# Установка «Рутокен для Safari» на iPhone без App Store

Приложение не опубликовано в App Store и TestFlight, поэтому каждый ставит его со своей подписью Apple ID.
Бесплатного Apple ID достаточно, но у такой установки есть ограничения:

- приложение работает **7 дней**, потом его нужно переустановить (Sideloadly/AltStore умеют обновлять);
- одним бесплатным Apple ID можно одновременно держать **3 подписанных приложения**, и каждое расширение
  считается отдельно. «Рутокен» — это приложение + 2 расширения, то есть все 3 места;
- нужен компьютер (Mac или Windows) и кабель для первой установки.

Есть два способа. **Способ 1 надёжный**, способ 2 проще, но см. предупреждение.

## Перед установкой (оба способа)

1. **Режим разработчика на iPhone** (iOS 16+): Настройки → Конфиденциальность и безопасность →
   Режим разработчика → включить, перезагрузить телефон, подтвердить.
2. **Apple ID для подписи.** Лучше отдельный, не основной: учётные данные вводятся в Xcode или Sideloadly.

## Способ 1. Собрать из исходников (Mac с Xcode)

1. Установите Xcode из App Store и XcodeGen: `brew install xcodegen`.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/whowho-agent/who-token.git && cd who-token
   ```
3. Xcode → Settings → Accounts → «+» → войдите своим Apple ID. Запомните Team ID (10 символов) у
   «Personal Team».
4. Создайте свой файл подписи:
   ```bash
   cp Config/Local.xcconfig.example Config/Local.xcconfig
   ```
   В нём укажите `DEVELOPMENT_TEAM = <ваш Team ID>` и `RB_BUNDLE_ID = com.example.RutokenBrowser.<ваш Team ID>`.
5. `xcodegen generate`, затем `open Rutoken.xcodeproj`, подключите iPhone кабелем, выберите его вверху и
   нажмите ▶︎ (Run). При вопросе про плагин SwiftLint — «Trust & Enable».
6. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

Через 7 дней повторите шаг 5.

## Способ 2. Sideloadly (Mac или Windows)

> **Предупреждение.** Переподпись меняет bundle id приложения. Сборка 1.0 после этого не находит свой драйвер
> токена и не передаёт PIN между приложением и Safari. Используйте этот способ с исправленной сборкой
> (готовится); до этого — способ 1.

1. Скачайте Sideloadly с официального сайта `sideloadly.io` и установите. На Windows также нужны iTunes и
   iCloud в версиях **с сайта Apple**, не из Microsoft Store.
2. Получите файл `Rutoken.ipa` у того, кто собирает приложение (в публичный репозиторий он не выкладывается:
   в подписанной сборке есть данные учётной записи сборщика).
3. Подключите iPhone кабелем, разблокируйте, на вопрос «Доверять этому компьютеру?» ответьте «Доверять».
4. В Sideloadly:
   - перетащите `Rutoken.ipa` в окно;
   - **Apple account** — ваш Apple ID;
   - в **Advanced options** оставьте расширения включёнными (не включайте «Remove app extensions»):
     без них приложение бесполезно;
   - нажмите **Start**, введите пароль Apple ID (и код двухфакторной аутентификации, если попросит).
5. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
6. Обновление раз в 7 дней: снова **Start** с тем же файлом (можно включить автообновление в Sideloadly,
   если компьютер и iPhone в одной сети).

### А AltStore?

AltStore сам занимает одно из 3 мест бесплатного Apple ID, а «Рутокену» нужны все 3 (приложение и два
расширения), поэтому на бесплатном Apple ID они вместе не помещаются. Используйте Sideloadly или способ 1.

## После установки (настройка один раз)

1. Подключите USB-токен Рутокен (USB-A — через переходник на USB-C).
2. Откройте «Рутокен» → **«Подключить токен к Safari»**.
3. Настройки → Приложения → Safari → Расширения → **«Рутокен»**: включить; доступ к сайтам — **«Разрешить»**.
4. Если внутренние сайты используют корпоративный корневой сертификат: установите профиль с ним
   (от ИТ или MDM) и включите полное доверие: Настройки → Основные → Об этом устройстве →
   Доверие сертификатам.
5. Откройте нужный сайт в Safari. Если PIN ещё не введён, «Рутокен» сам откроет страницу ввода PIN;
   после ввода сайт откроется. PIN хранится на телефоне 24 часа.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Не удаётся проверить приложение» / не запускается | Доверьте разработчика (VPN и управление устройством), включите режим разработчика |
| Приложение перестало открываться | Прошло 7 дней — переустановите |
| «Система не видит расширение» при подключении к Safari | Переустановите с включёнными расширениями; при способе 2 — нужна исправленная сборка |
| Safari: «не удаётся установить безопасное соединение» | Введите PIN кнопкой «Рутокен» (значок «аА») и обновите страницу; проверьте, что токен подключён |
| Safari: «сертификат недействителен» | Не установлен или не включён корпоративный корневой сертификат |
| «PIN не подошёл, осталось попыток: N» | Введите правильный PIN; после исчерпания попыток токен разблокирует администратор |
