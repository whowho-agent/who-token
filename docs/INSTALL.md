# Установка «Рутокен для Safari» на iPhone без App Store

Приложение не опубликовано в App Store и TestFlight, поэтому каждый ставит его со своей подписью Apple ID.
Бесплатного Apple ID достаточно, но у такой установки есть ограничения:

- приложение работает **7 дней**, потом его нужно переустановить (Sideloadly/AltStore умеют обновлять);
- одновременно активны **не больше 3 установленных так приложений** (расширения мест не занимают);
- каждое приложение и каждое его расширение регистрирует свой **App ID**, а бесплатный Apple ID может
  зарегистрировать **не больше 10 App ID**, каждый действует неделю. «Рутокен» — приложение + 2 расширения,
  то есть 3 App ID. Переустановка с тем же bundle id новых App ID не тратит;
- нужен компьютер (Mac или Windows) и кабель для первой установки.

Есть три способа. **Способ 1 надёжный** (сборка из исходников); способы 2 и 3 проще.

## Перед установкой (оба способа)

1. **Режим разработчика на iPhone** (iOS 16+): Настройки → Конфиденциальность и безопасность →
   Режим разработчика → включить, перезагрузить телефон, подтвердить.
2. **Apple ID для подписи.** Лучше отдельный, не основной: учётные данные вводятся в Xcode или Sideloadly.

## Способ 1. Собрать из исходников (Mac с Xcode)

1. Установите Xcode из App Store и XcodeGen: `brew install xcodegen`.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/whowho-agent/who-token.git && cd who-token
   ```
3. Xcode → Settings → Accounts → «+» → войдите своим Apple ID. Запомните Team ID (10 символов) у
   «Personal Team».
4. Создайте свой файл подписи:
   ```bash
   cp Config/Local.xcconfig.example Config/Local.xcconfig
   ```
   В нём укажите `DEVELOPMENT_TEAM = <ваш Team ID>` и `RB_BUNDLE_ID = com.example.RutokenBrowser.<ваш Team ID>`.
5. `xcodegen generate`, затем `open Rutoken.xcodeproj`, подключите iPhone кабелем, выберите его вверху и
   нажмите ▶︎ (Run). При вопросе про плагин SwiftLint — «Trust & Enable».
6. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».

Через 7 дней повторите шаг 5.

## Способ 2. Sideloadly (Mac или Windows)

Нужен файл **`Rutoken-unsigned.ipa`** — нейтральная сборка без чьей-либо подписи (bundle id
`com.example.RutokenSafari`). Готовая лежит в репозитории: [`releases/`](../releases/) (рядом — контрольная
сумма `.sha256`); пересобрать можно скриптом `tools/build-neutral-ipa.sh`. Обычная `Rutoken.ipa`,
подписанная чужим Apple ID, не подойдёт.

1. Скачайте Sideloadly с официального сайта `sideloadly.io` и установите. На Windows также нужны iTunes и
   iCloud в версиях **с сайта Apple**, не из Microsoft Store.
2. Подключите iPhone кабелем, разблокируйте, на вопрос «Доверять этому компьютеру?» ответьте «Доверять».
3. В Sideloadly:
   - перетащите `Rutoken-unsigned.ipa` в окно;
   - **Apple account** — ваш Apple ID;
   - в **Advanced options** оставьте расширения включёнными (не включайте «Remove app extensions»):
     без них приложение бесполезно; bundle id можно оставить как есть;
   - нажмите **Start**, введите пароль Apple ID (и код двухфакторной аутентификации, если попросит).
4. На iPhone: Настройки → Основные → VPN и управление устройством → ваш Apple ID → «Доверять».
5. Обновление раз в 7 дней: снова **Start** с тем же файлом (можно включить автообновление в Sideloadly,
   если компьютер и iPhone в одной сети).

> Если после установки «Подключить токен к Safari» пишет «Система не видит расширение» или PIN, введённый
> в Safari, не принимается — переустановите, убедившись, что расширения не удалены; если не помогло,
> используйте способ 1 и сообщите, что не сработало.

## Способ 3. AltStore

Подходит, если AltStore уже стоит или удобнее ставить приложения прямо с телефона. AltStore сам занимает одно
из 3 мест активных приложений и 1 App ID; «Рутокен» — ещё одно место и 3 App ID.

1. Установите **AltServer** на Mac или Windows и с его помощью **AltStore** на iPhone — по инструкции
   на `altstore.io` (ваш Apple ID, кабель или одна сеть Wi-Fi с компьютером).
2. Перенесите `Rutoken-unsigned.ipa` на iPhone (AirDrop, «Файлы», почта).
3. AltStore → **My Apps** → «+» → выберите `Rutoken-unsigned.ipa`.
4. Если AltStore предложит **удалить расширения** («Remove App Extensions»), чтобы уложиться в лимит App ID, —
   **откажитесь**: без расширений приложение бесполезно. Если App ID не хватает, дождитесь, пока освободятся
   старые (через неделю после регистрации), или удалите ненужные в **My Apps → View App IDs**.
5. AltStore обновляет подпись в фоне, когда рядом запущен AltServer; иначе — «Refresh All» раз в неделю.

## После установки (настройка один раз)

1. Подключите USB-токен Рутокен (USB-A — через переходник на USB-C).
2. Откройте «Рутокен» → **«Подключить токен к Safari»**.
3. Настройки → Приложения → Safari → Расширения → **«Рутокен»**: включить; доступ к сайтам — **«Разрешить»**.
4. Если внутренние сайты используют корпоративный корневой сертификат — установите его, см.
   [«Корпоративный корневой сертификат»](#корпоративный-корневой-сертификат) ниже.
5. Откройте нужный сайт в Safari. Если PIN ещё не введён, «Рутокен» сам откроет страницу ввода PIN;
   после ввода сайт откроется. PIN хранится на телефоне 24 часа.

## Корпоративный корневой сертификат

### Нужен ли он

Нужен, если серверные сертификаты внутренних сайтов выпущены собственным центром сертификации (CA)
организации, а не публичным (DigiCert, GlobalSign, Let's Encrypt и т. п.). Признак — Safari на iPhone
пишет «Это соединение не является частным» / «Сертификат для этого сервера недействителен»,
хотя на рабочем компьютере сайт открывается без предупреждений (там корень уже установлен).

Это не связано с токеном: токен подтверждает, кто вы; корневой сертификат — что сервер настоящий.

**Если телефон под управлением MDM** (корпоративный профиль уже стоит), корень обычно установлен
и доверие включено — ничего делать не нужно.

### Где взять

- **Кнопкой в «Рутокене».** В приложении: «Установить корневой сертификат сайта…», введите адрес сайта.
  В Safari: кнопка «Рутокен» → «Сертификат этого сайта…». «Рутокен» сам найдёт корень (из цепочки сайта или
  по ссылке издателя в ней), проверит, что он подтверждает сертификат этого сайта, покажет отпечаток
  SHA-256 и после подтверждения отдаст профиль на установку. **Отпечаток обязательно сверьте с ИТ** —
  корень приходит по ещё не доверенному соединению, и в чужой сети он может быть подменён.
- **Лучше всего — у ИТ:** готовый профиль `.mobileconfig` или файл сертификата (`.cer`, `.crt`, `.pem`) и его
  **отпечаток SHA-256** для сверки.
- Нужен именно **корневой** сертификат (Root CA), а не промежуточный и не сертификат сайта.
- Если есть только файл сертификата, сделайте из него профиль на Mac:
  ```bash
  tools/make-root-profile.sh "Root CA.cer"
  ```
  Скрипт создаст `<имя CA>.mobileconfig` и выведет имя, срок действия и отпечаток SHA-256 — сверьте
  отпечаток с тем, что дала ИТ. (Можно передавать на iPhone и сам `.cer` — шаги те же, iOS тоже
  предложит его установить.)

### Как перенести на iPhone

Файл нужно открыть на iPhone так, чтобы iOS распознала профиль. Подходит любой из способов:

- **AirDrop с Mac:** в Finder правый клик по файлу → «Поделиться» → AirDrop → ваш iPhone → «Принять».
- **Почта:** отправьте файл себе и откройте вложение во встроенной «Почте».
- **Safari:** откройте ссылку на файл именно в Safari (Chrome и другие браузеры профили не устанавливают).
- **Файлы:** сохраните файл в «Файлы» (iCloud Drive) и коснитесь его там.

На экране появится «Профиль загружен». Загруженный профиль ждёт установки около 8 минут; если не
успели — откройте файл ещё раз.

### Как установить

1. Откройте **Настройки**. Вверху появится строка **«Профиль загружен»** — коснитесь её.
   (Если её нет: Настройки → Основные → **VPN и управление устройством** → в разделе «Загруженный профиль».)
2. Проверьте имя профиля («Корневой сертификат: …») и нажмите **«Установить»** в правом верхнем углу.
3. Введите **код-пароль** iPhone.
4. iOS покажет предупреждение о корневом сертификате — это ожидаемо. Нажмите **«Установить»** ещё раз,
   затем **«Готово»**.

### Как включить доверие (обязательно)

Установленный вручную корень **по умолчанию не используется** для проверки сайтов — его нужно включить:

1. Настройки → **Основные** → **Об этом устройстве**.
2. Прокрутите в самый низ → **«Доверие сертификатам»**.
3. В разделе «Включить полное доверие для корневых сертификатов» включите переключатель у вашего
   сертификата → **«Продолжить»**.

Если пункта «Доверие сертификатам» нет — профиль не установлен (вернитесь к предыдущему разделу).

### Как проверить

- **Отпечаток:** Настройки → Основные → VPN и управление устройством → ваш профиль → «Подробнее» →
  сертификат → внизу «SHA-256». Он должен совпасть с тем, что дала ИТ.
- **Сайт:** закройте вкладку с ошибкой и откройте внутренний сайт заново — предупреждения о сертификате
  быть не должно.

### Безопасность и удаление

- Корень с полным доверием позволяет его владельцу выпускать сертификаты для **любых** сайтов, которым
  поверит ваш iPhone. Устанавливайте только корень своей организации и только после сверки отпечатка.
- Удалить: Настройки → Основные → VPN и управление устройством → профиль → **«Удалить профиль»**.
  Доверие отключится вместе с ним.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Не удаётся проверить приложение» / не запускается | Доверьте разработчика (VPN и управление устройством), включите режим разработчика |
| Приложение перестало открываться | Прошло 7 дней — переустановите |
| «Система не видит расширение» при подключении к Safari | Переустановите с включёнными расширениями (в Sideloadly не включайте «Remove app extensions») |
| Safari: «не удаётся установить безопасное соединение» | Введите PIN кнопкой «Рутокен» (значок «аА») и обновите страницу; проверьте, что токен подключён |
| Safari: «соединение не является частным» / «сертификат недействителен» | Установите корпоративный корень и включите доверие, см. [выше](#корпоративный-корневой-сертификат) |
| «PIN не подошёл, осталось попыток: N» | Введите правильный PIN; после исчерпания попыток токен разблокирует администратор |
