# Промежуточные CA клиентского сертификата

На токене хранится только конечный сертификат пользователя. Если сервер требует полную цепочку
(например, AD FS), положите сюда PEM-файлы промежуточных CA, выпустивших клиентский сертификат.
Прокси добавит в цепочку тот, чей subject совпадает с issuer сертификата на токене.

Файлы `*.pem` в этой папке в git не попадают: это сертификаты конкретной организации.
