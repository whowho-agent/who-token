# Дополнительные корневые сертификаты

Корневые CA организации, которыми прокси проверяет перехваченные серверы в дополнение к системным
(нужно, если серверные сертификаты внутренних сайтов выпущены корпоративным CA, которому iOS не доверяет).
Формат — PEM, по одному или несколько сертификатов в файле.

Файлы `*.pem` в этой папке в git не попадают: это сертификаты конкретной организации.
